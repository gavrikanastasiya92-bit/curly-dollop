## Как подключить фото дальше

1. Положить оптимизированные файлы (jpg/webp, сжатые под веб) в эту папку с понятным именем, например `room-house.jpg`.
2. В `index.html` заменить соответствующий `<div class="media-placeholder" data-slot="...">...</div>` на `<img src="assets/images/<имя файла>" alt="...">` (для фото внутри `.about-media`, `.t-media`, `.f-media`, `.room-photo` стили уже подключены автоматически — см. `css/style.css`).
3. Для hero-фона используется `<img class="ph-bg kenburns" ...>` — уже готово, менять файл `hero.jpg` можно просто заменив содержимое.

Видео (MOV) перед использованием на сайте лучше сконвертировать в mp4/webm и сжать — исходники из Drive весят по 50–200 МБ.
