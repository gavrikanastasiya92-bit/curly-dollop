# Фото и видео — куда и как добавлять

Сейчас в лендинге вместо реальных фото стоят плейсхолдеры (пунктирная рамка с подписью), чтобы можно было утвердить структуру и тексты до отбора кадров.

Сырые материалы уже загружены в Google Drive (папка «фото/видео», ~80 HEIC/MOV файлов + архив). Их ещё нужно отсмотреть и отобрать лучшие кадры под каждый слот.

## Слоты на странице (атрибут `data-slot` в index.html)

| Слот | Секция | Что нужно |
|---|---|---|
| `hero` | Hero (главный экран) | Широкий, атмосферный кадр территории/юрт/озера. В брифе есть референс на формат «статичное фото, только волосы/дым на ветру» |
| `about` | О месте | Территория лагеря |
| `room-standard` | Размещение — Юрта Стандарт | Интерьер/экстерьер стандартной юрты |
| `room-vip` | Размещение — ВИП юрта | Интерьер ВИП юрты |
| `room-beach` | Размещение — Пляжная премиум юрта | Юрта у воды, вид на озеро из кровати |
| `room-house` | Размещение — Премиум Юрта-Дом | Терраса, пергола, экстерьер |
| `territory` | Территория и активности | Сапборды, зоны отдыха |
| `retreats` | Ретриты | Йога-бунгало, костровая зона (у Алимы в Instagram таких кадров почти нет — искать в присланных материалах) |

Отдельно: баня (`#banya`) — фото/видео пока не найдены нигде (открытый пункт в брифе), карта в разделе «Как добраться» — нужен embed по точному адресу.

## Как подключить фото, когда кадры отобраны

1. Положить оптимизированные файлы (jpg/webp, сжатые под веб) в эту папку с понятным именем, например `hero.jpg`, `room-standard.jpg`.
2. В `index.html` заменить соответствующий `<div class="media-placeholder" data-slot="...">...</div>` на `<img src="assets/images/<имя файла>" alt="...">`.
3. Для hero-фона — см. `.ph-bg` в `css/style.css`, его нужно будет заменить на `background-image` на `#hero`.

Видео (MOV) перед использованием на сайте лучше сконвертировать в mp4/webm и сжать — исходники из Drive весят по 50–200 МБ.
