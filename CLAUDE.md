# Ak-Tengir — заметки для Claude

Лендинг юрточного лагеря на Иссык-Куле. Чистый HTML/CSS/JS, без сборки. Полное описание проекта — в `README.md`.

## Дизайн-система

`design/design-system.html` — утверждённая дизайн-система лендинга. Открывается прямо в браузере (двойной клик / `python3 -m http.server`), ничего собирать не нужно.

**Перед любой визуальной правкой сайта (цвета, шрифты, кнопки, карточки, переходы между секциями, карта, промпты для фото) — сначала открой и прочитай этот файл.** Он описывает:

- палитру (токены `--lake`, `--ink`, `--terracotta`, `--terracotta-deep`, `--cream`, `--wood`, `--sage`, `--gold` и их назначение)
- типографику (Bitter + Work Sans уже в проекте; hero-шрифт пока не выбран — в разделе «Типографика» 4 кандидата на кириллице, решение за автором проекта)
- кнопки, карточки, чипы/бейджи — уже используются в `css/style.css`, дизайн-система их фиксирует как систему
- приёмы для секций, которые ещё предстоит сверстать: мягкий нахлёст / рваный край / отражение-мост между блоками, sticky-сплит (текст или фото фиксируются, второе скроллится), метки-нумерация только для реальных последовательностей (шаги брони), иллюстративная карта вместо гугл-эмбеда
- ритм ленты — реальный порядок секций `index.html` с рекомендованной высотой/темпом и тем, где именно уместны переходы (не на каждом стыке)
- промпты для генерации/подбора фото под каждый слот сайта + общий стилевой суффикс, чтобы фото из разных источников выглядели одной съёмкой
- чек-лист «Без ИИ-шаблона» — от чего осознанно отказались (декоративные над-заголовки, одинаковые карточки/радиусы на всё подряд, нумерация ради вида)

`css/style.css` остаётся источником правды для уже реализованных стилей. `design/design-system.html` — референс для того, что дорабатывается или ещё не сверстано. Когда токен/приём оттуда переносится в код, `--ink` и `--terracotta-deep` уже определены в дизайн-системе как названные версии литералов, которые раньше были в `css/style.css` (`#0F221F`, `#93412b`).

## Как попросить сайт по дизайн-системе

Например: «Перевёрстай hero по `design/design-system.html`» или «Примени палитру и токены из дизайн-системы к `css/style.css`». Файл достаточно назвать по пути — читать его не нужно просить отдельно, он уже описан выше.
