# Буклеты Ак-Тенгир

Печатные материалы в системе «Актенгир 2» (Cormorant Garamond + Montserrat, один фон, тонкие линии).

## Утверждено 11.10.2026 — образец

Папка `утверждено 2026-10-11/` — PDF для типографии на RU, EN, KY, каждый в двух фонах (молочный и голубой):

- **Гармошка на 8 панелей** по ТЗ заказчицы (`accordion8.py`, тексты `texts/accordion8-*.json`). Панель 99×210 мм, лист 396×210, вылеты 3 мм. Снаружи: контакты · отдых · что рядом · обложка; внутри: о нас · проживание · баня · группы.
- **Листовка А4 про баню** для соседних мест отдыха (`banya.py`, тексты `texts/banya-*.json`). Вылеты 3 мм.

Утверждены как образец: **фото позже будут заменены**. Чтобы заменить фото, поменяйте имя файла в шаблоне (или в `stay`/`near` в текстах), положите фото в `site/img/` и пересоберите.

Цены везде «от …» и строка «Актуальные цены и специальные условия обсуждаются лично» — по просьбе заказчицы.
Киргизский текст — черновой перевод, ждёт вычитки носителем языка вместе с сайтом.

## Пересборка

```
cd design/booklet
python3 accordion8.py && python3 banya.py          # HTML в out/
node render.mjs accordion8-ru                        # PDF и PNG-превью в out/ (имя без .html)
```

`build.py` — первый вариант буклета на 6 панелей (А4, 2 сгиба), черновики — в `drafts/`.
