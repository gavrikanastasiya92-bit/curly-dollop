# Сайт Ак-Тенгир (боевая версия)

Собран из утверждённого макета «Актенгир 2» (`design/aktengir-2/`, утверждён заказчицей 02.10.2026). Чистый HTML/CSS/JS, сборки нет.

- `index.html` — русская версия, адрес `/`
- `en/index.html` — английская, адрес `/en/`. **Руками не править**: собирается скриптом. Перевод утверждён 03.10.2026
- `i18n/en.json` — перевод: «русская строка» → «английская строка»
- `img/` — фото (сжаты до 1280 px, первый экран и карта до 2000 px), логотипы, `og.jpg` для превью ссылок
- `robots.txt`, `sitemap.xml`, `_headers` — для поиска и кеша (Cloudflare Pages / Netlify читают `_headers`)

## Правка текстов

1. Русский текст — в `index.html`.
2. Перевод — в `i18n/en.json`. Ключ — русская строка ровно так, как она стоит на странице (пробелы не важны).
3. Собрать языковые версии (EN и KY): `python3 tools/build_lang.py` из корня репозитория. Скрипт перечислит строки, для которых нет перевода.

## Публикация — вручную, Cloudflare не связан с GitHub

Сайт aktengir.com живёт в Cloudflare на аккаунте Алимы, проект **tiny-scene-c4f1** (Workers & Pages). Все версии загружаются **вручную**: изменения в GitHub (в том числе принятые запросы на объединение) **сами на сайт не попадают**.

Как опубликовать:
1. Взять папку `site/` из ветки `main` (Claude может прислать её архивом; `README.md` внутри не нужен).
2. Cloudflare → Workers & Pages → `tiny-scene-c4f1` → Deployments → **New deployment** → загрузить содержимое папки → Deploy.
3. Проверить: открыть исходный код https://aktengir.com/?v=<любое число> и найти в нём то, что меняли.

Имя `curly-dollop` в `wrangler.jsonc` с проектом в Cloudflare не совпадает; если когда-нибудь подключать автопубликацию из GitHub, имя нужно поменять на `tiny-scene-c4f1`.
