# Ak-Tengir — лендинг

Одностраничный лендинг юрточного лагеря Ak-Tengir на южном берегу Иссык-Куля. Чистый HTML/CSS/JS, без сборки — открывается напрямую в браузере или через любой статический хостинг.

## Структура проекта

```
index.html          — разметка и тексты всех секций
css/style.css        — стили (переменные бренда, секции, адаптив)
js/main.js           — hero-частицы, появление шапки при скролле, reveal-анимации
assets/images/        — сюда позже лягут фото/видео (см. assets/images/README.md)
```

## Как посмотреть локально

Открыть `index.html` в браузере, либо запустить любой статический сервер, например:

```
python3 -m http.server 8000
```

## Секции лендинга

1. **Hero** — обещание + два CTA
2. **О месте** — позиционирование, факты о территории
3. **Три повода приехать** — проживание / баня без ночёвки / ретрит
4. **Размещение** — 4 категории юрт с ценами
5. **Баня** — цена и условия, доступна без проживания
6. **Питание** — своя органика, завтрак/обед/ужин
7. **Территория и активности** — сапборд (отдельно от проживания), pet-friendly
8. **Ретриты** — ведёт приглашённый практик (Алима Назаралиева)
9. **Отзывы** — заглушки, ждут реальных отзывов
10. **Как добраться** — адрес, логистика, карта (заглушка под embed)
11. **Бронирование** — WhatsApp и телефон

Контент и цены — по брифу заказчика (`Ak-Tengir — бриф по лендингу.docx` на Google Drive).

## Решено по брифу (последнее уточнение)

- Частные туры — убраны из объёма проекта, на лендинге не упоминаются
- Про Алиму на лендинге пока ничего не пишем (блок ретритов остаётся без персоналии)
- Меню обеда/ужина — без перечисления состава, акцент только на натуральность и свежесть (состав каждый день разный)
- Сапборд — отдельно от проживания, в стоимость не входит, цена уточняется
- E-foil — убран из проекта полностью

## Открытые вопросы (нужно уточнить у заказчика)

- Как в итоге представлять Алиму и ретриты, когда решение будет готово
- Обед/ужин включены в премиум-категории или отдельно
- Минимальное количество ночей, способы оплаты
- Какой канал бронирования показывать первым (WhatsApp / Booking.com / форма)
- Нужна ли англоязычная версия текстов
- Словесный ориентир адреса (кроме Plus Code)
- Фото/видео бани — не найдены ни у отеля, ни у Алимы
- Цена сапборда
