# Ak-Tengir — лендинг

Одностраничный лендинг юрточного лагеря Ak-Tengir на южном берегу Иссык-Куля. Чистый HTML/CSS/JS, без сборки — открывается напрямую в браузере или через любой статический хостинг.

## Структура проекта

```
index.html          — разметка и тексты всех секций
css/style.css        — стили (переменные бренда, секции, адаптив)
js/main.js           — hero-частицы, появление шапки при скролле, reveal-анимации
assets/images/        — сюда позже лягут фото/видео (см. assets/images/README.md)
```

## Как посмотреть локально

Открыть `index.html` в браузере, либо запустить любой статический сервер, например:

```
python3 -m http.server 8000
```

## Секции лендинга

1. **Hero** — обещание + два CTA
2. **О месте** — позиционирование, ~20 лет истории, факты о территории
3. **История и основатель** — Женишбек Назаралиев (врач-психиатр, основатель мед. центра), первые 10 лет — закрытое пространство для спортсменов/знаменитостей
4. **Три повода приехать** — проживание / баня без ночёвки / ретрит
5. **Размещение** — 4 категории юрт с ценами, круглогодичная работа, ссылка на обзор блогера
6. **Баня** — настоящая юрта в 5–10м от воды, цена и условия, доступна без проживания
7. **Питание** — повар тётя Диля, пермакультура, «от земли к столу»
8. **Территория и активности** — сапборд (отдельно от проживания), pet-friendly
9. **Ретриты** — открытая площадка (свои программы + гости + корпоративные заказы), ведёт постоянный практик (отец Алимы)
10. **Отзывы** — заглушки, ждут реальных отзывов
11. **Как добраться** — адрес, логистика, карта (заглушка под embed)
12. **Бронирование** — WhatsApp и телефон

Контент и цены — по брифу заказчика (`Ak-Tengir — бриф по лендингу.docx` на Google Drive).

## Решено по брифу (последнее уточнение)

- Частные туры — убраны из объёма проекта, на лендинге не упоминаются
- Про Алиму на лендинге по-прежнему не пишем по имени (только "постоянный практик" / "его дочь")
- Добавлен блок про историю и основателя — Женишбек Назаралиев (врач-психиатр, доктор мед. наук, основатель Медицинского центра доктора Назаралиева с 1991 года; публичная фигура — см. источники ниже), без персональных подробностей сверх публичных фактов
- Ретриты репозиционированы как открытая площадка: свои программы + приглашённые практики + корпоративные ретриты/тимбилдинг, с возможностью закрыть весь лагерь под одну группу
- Размещение: 11 юрт + 2 пляжных домика + 1 Premium домик, круглогодичная работа (утепление в процессе), добавлена ссылка на обзор блогера у Premium Юрта-Дом
- Баня: уточнено, что это настоящая юрта в 5–10м от воды с панорамным предбанником; добавлена опция ритуала с белой глиной по запросу
- Питание: указано имя повара (тётя Диля, 10+ лет), добавлена тема пермакультуры и «от земли к столу», состав меню по-прежнему не расписываем
- Сапборд — отдельно от проживания, в стоимость не входит, цена уточняется
- E-foil — убран из проекта полностью

## Дизайн-референсы и анимации

Шрифтовая пара Work Sans + Bitter — по референсу [fontpair.co/pairings/work-sans-bitter](https://fontpair.co/pairings/work-sans-bitter).

Анимации — адаптация motion-референсов из таблицы (`motionsites.ai` прompts, anchor-ai, lumina-footer):

- **Плавающее меню** (референс anchor-ai) — при скролле шапка превращается в плавающую овальную панель с тенью, а пункты меню появляются с лёгким сдвигом по очереди
- **Ken Burns** — все фото/плейсхолдеры (класс `.kenburns`, а также любой `<img>` внутри `.media-placeholder`) медленно «дышат» — плавный зум 22 сек, зациклен
- **Искры/пепел** (`.particles`/`.particle` в `js/main.js`) — сейчас в hero и в блоке «История»; можно добавить в любую секцию, обернув контейнер в `<div class="particles"></div>` с `position:relative` у родителя
- **Мерцание воды** (класс `.shimmer`, референс на «движение воды/огня») — сейчас на плейсхолдерах «Территория» и карты в «Как добраться»; диагональный блик света, как рябь на озере
- Все анимации уважают `prefers-reduced-motion: reduce` — отключаются для пользователей с этой настройкой

Когда встанут реальные фото/видео — эффекты Ken Burns и shimmer сработают автоматически (see `assets/images/README.md`). Для настоящих cinemagraph-эффектов (шевелящиеся волосы, живой костёр) в присланных материалах на Google Drive много .MOV роликов — стоит отдельно отсмотреть и подобрать короткие зацикленные клипы под hero/баню вместо статичных фото.
